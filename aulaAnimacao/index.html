Aula prática

Movimento com CSS

Transições para respostas imediatas. Animações para mostrar mudanças ao longo do tempo.

IDEIA PRINCIPAL

Uma animação deve explicar alguma coisa.

Ela pode indicar que um botão recebeu o clique, que uma tarefa está sendo carregada ou que um conteúdo acabou de aparecer.

@keyframes + animation
01

Transition e transform: resposta a uma interação

A transição suaviza a mudança entre o estado normal e o estado de :hover ou :focus-visible.

Passe o mouse no cartão

Em telas touch, toque no cartão para enxergar a mudança de estado.

transition: transform .25s ease, background-color .25s ease;

translate()

Move o item nos eixos X e Y.

translateY(-12px)

scale()

Aumenta ou reduz sem mudar o layout.

scale(1.12)

rotate()

Gira o elemento ao redor do centro.

rotate(12deg)

skew()

Inclina o elemento em um eixo.

skewX(-10deg)

Combinação

Mais de uma transformação no mesmo efeito.

translateY(-8px) rotate(-3deg)

transform-origin

Muda o ponto usado para girar.

transform-origin: left;
02

@keyframes: uma sequência de estados

Use quando o elemento precisa percorrer mais de um ponto, sem depender da interação da pessoa.

Carregamento

animation: pulse 1s ease-in-out infinite;

Chamada de atenção

animation: float 1.8s ease-in-out infinite;
Nova mensagem 1
03

Controle de tempo

Experimente alterar a duração. Valores menores deixam o movimento mais rápido.

CSS

animation: move 1.2s linear infinite alternate;

04

Outros efeitos úteis

Cada efeito abaixo aparece em situações diferentes de uma interface real.

Entrada de conteúdo

animation-fill-mode: both;

Uma sequência curta deixa clara a ordem em que os itens chegaram.

Digitando uma mensagem

steps(18, end)
Mensagem enviada!

steps() cria intervalos marcados, sem o movimento contínuo de ease.

Brilho em carregamento

background-position

Útil quando o espaço do conteúdo já está reservado enquanto os dados chegam.

✓

Cuidado com excesso de movimento

Evite animações longas, rápidas ou que escondam conteúdo. O CSS abaixo respeita a preferência de reduzir movimento configurada no sistema.

@media (prefers-reduced-motion: reduce) { ... }
