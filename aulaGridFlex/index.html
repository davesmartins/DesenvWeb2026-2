CSS Grid vs Flexbox

Entenda visualmente a diferença entre as duas principais ferramentas de Layout do CSS moderno.

Flexbox

1. Flexbox (Layout Unidimensional - 1D)

O Flexbox se destaca no alinhamento de itens ao longo de uma única direção (linha ou coluna). Perfeito para menus, barras de ferramentas e cartões alinhados.

Exemplo 1.1: Barra de Navegação Header (Linha)

CSS Usado: display: flex; justify-content: space-between; align-items: center;

🔴 Logo (flex item 1)
Inicio Sobre Serviços
🔵 Botão Entrar (flex item 3)

Exemplo 1.2: Cards Flexíveis que Quebram Linha (Flex Wrap)

CSS Usado: display: flex; flex-wrap: wrap; gap: 15px;

Card A flex: 1 1 200px
Card B flex: 1 1 200px
Card C flex: 1 1 200px
CSS Grid

2. CSS Grid (Layout Bidimensional - 2D)

O CSS Grid permite controlar linhas e colunas simultaneamente. É ideal para organizar a estrutura geral da página ou criar grades complexas.

Exemplo 2.1: Layout Completo de Aplicação (Header, Sidebar, Principal, Footer)

CSS Usado: display: grid; grid-template-areas: "header header" "sidebar main" "footer footer";

HEADER (Cabeçalho) grid-area: header
SIDEBAR (Menu Lateral) grid-area: sidebar
MAIN CONTENT (Conteúdo Principal) grid-area: main

O Grid organiza com precisão as regiões bidimensionais da tela.

FOOTER (Rodapé) grid-area: footer

Exemplo 2.2: Grid Automático e Responsivo (Auto-Fit)

CSS Usado: display: grid; grid-template-columns: repeat(auto-fit, minmax(180px, 1fr));

Boas Práticas

3. Quando usar qual? (Resumo Didático)

⚡ Use FLEXBOX para:

  • Alinhar elementos em 1 única direção (horizontal ou vertical).
  • Distribuir espaço entre botões, itens de menu e ícones.
  • Centralizar um elemento vertical e horizontalmente com facilidade.
  • Componentes pequenos e médios da interface.

📐 Use CSS GRID para:

  • Criar a estrutura geral da página (Macro Layout).
  • Organizar elementos em 2 direções (Linhas E Colunas ao mesmo tempo).
  • Superposição (overlap) de elementos.
  • Galerias de fotos e dashboards com alinhamento estrito.
