2. HTML, CSS e JS: cada um com seu papel

É a mesma casa, três trabalhos diferentes.

🧱 HTML

A estrutura. Define o que existe na página: títulos, parágrafos, botões, imagens.

🎨 CSS

A aparência. Define cores, espaçamentos, fontes e o layout (Flexbox, Grid...).

⚡ JavaScript

O comportamento. Reage a cliques, muda o conteúdo, valida formulários, busca dados.

DOM

3. Como o JS "enxerga" a página: o DOM

Quando o navegador lê seu HTML, ele monta uma árvore de elementos na memória chamada DOM (Document Object Model). O JavaScript não edita o arquivo .html — ele conversa com essa árvore, e a tela é atualizada na hora.

Exemplo: este HTML...

<body>
  <h1 id="titulo">Minha Página</h1>
  <p class="texto">Um parágrafo</p>
  <button>Clique aqui</button>
</body>

...vira esta árvore (o DOM):

  • body
    • h1 id="titulo"
    • p class="texto"
    • button

O JS pega um "nó" dessa árvore e mexe nele

CSS Usado: document.querySelector("#titulo") encontra o elemento; depois mudamos alguma propriedade dele, como .textContent ou .style.color.
