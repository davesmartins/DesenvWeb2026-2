2. Exemplo de Montagem com Flexbox

Layout fluido usando display: flex, flex-direction, justify-content e align-items

Header Flex (justify-content: space-between)

Painel Flexbox

Conteúdo Principal (flex: 3)

No Flexbox, não precisamos calcular larguras com px nem usar margin-right manual. O atributo flex: 3 expande este bloco proporcionalmente.

Se a tela dimunuir, os elementos se ajustam automaticamente de forma responsiva.

Sidebar (flex: 1)

Ocupa 1/4 do espaço horizontal automaticamente.

Badge Flex (align-self: flex-end)
